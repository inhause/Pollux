# Overview
> My personal Arch-based dots for [MangoWM](https://mangowm.github.io/). I use [awww](https://codeberg.org/LGFae/awww) for wallpaper management,terminal shell is [zsh](https://www.zsh.org) with [Oh-My-Zsh](https://ohmyz.sh)

***Please git clone to ~/.config/mango*** then run
`ln -s ~/.config/mango/fish ~/.config/fish`
`ln -s ~/.config/mango/foot ~/.config/foot`

# Packages in use
- foot (terminal)
- waterfox (browser)
- nautilus (explorer)
- awww (wallpapers)
- dunst (notifs)
- fish (shell)
- noctalia (shell)
